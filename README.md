## ✨ Core Experience

### 🎭 Cinematic Project Scroll
- **Dynamic Linear Transitions:** Projects move through a synchronized scroll context with scale-down and fade-out effects as they exit.
- **Project Index Layering:** Large, italicized background numerals track your progression through the showroom.
- **Image Parallax:** Subtle internal parallax on project previews for an immersive "window" feel.

### 🧠 Strategic Philosophy Page
- **The How & Why:** A dedicated route detailing my build process, design systems approach, and technical leadership principles.
- **Narrative Content:** Human-centric content that goes beyond code, focusing on the architectural mindset behind the projects.

### 🔭 Unique Precision Cursor
- **Dual-State System:** A high-precision minimalist cursor with a trailing ring that responds to hover and click states.
- **Intelligent Blending:** Uses `mix-blend-difference` for perfect visibility across obsidian dark and stone light modes.
- **Mobile Optimized:** Automatically unmounts on touch devices to ensure native frictionless navigation.

## 🛠️ Tech Stack & Mastery

### Frontend & Animation
- **Framework:** [Next.js 16](https://nextjs.org/) (App Router, Turbopack)
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/) (using the new @theme engine)
- **Motion:** [Framer Motion 12](https://www.framer.com/motion/) & [GSAP](https://gsap.com/)
- **Smooth Interaction:** [Lenis](https://lenis.darkroom.engineering/) for inertia scrolling

### Full-Stack Intelligence
- **Languages:** TypeScript, JavaScript, Python
- **Backend/DB:** Node.js, Express, Prisma, PostgreSQL
- **Tools:** GitHub Workspace, Bash/Shell, Figma, Vercel
